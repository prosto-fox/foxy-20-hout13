# 🦊 Фокси — публичная мобильная версия

## Публикация через Render
1. Создайте GitHub-репозиторий и загрузите эти файлы.
2. В Render выберите **New → Blueprint** и подключите репозиторий.
3. Render прочитает `render.yaml` и создаст веб-сервис.
4. После деплоя получите публичный `https://...onrender.com` адрес.
5. Откройте адрес на телефоне.

SQLite хранится на постоянном диске Render. Каждый браузер получает отдельный профиль игрока.

## Docker
`docker build -t foxy-20-hours .`
`docker run -p 5000:5000 -e SECRET_KEY=change-this -v "$(pwd)/data:/app/data" foxy-20-hours`

Чат пока работает в демо-режиме; внешний AI API можно подключить следующим этапом.
